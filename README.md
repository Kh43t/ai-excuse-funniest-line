One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline. A tiny deterministic Node program that writes the line to /output/entry.txt.

The line: "I delegated your deadline to a sub-agent, who delegated it to another sub-agent, who is currently asking me for an extension."

## Run it

```sh
node main.ts
```
